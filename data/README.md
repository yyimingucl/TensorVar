# Data 

This folder contains the data files for the Tensor-Var project. Download the data from the URL below to the corresponding folder

## Contents

|    |Data shape|URL|Size|
|---------|---------|---------|---------|
| Lorenz-96 (D=40) | (N,T,D) | | 
| Lorenz-96 (D=80) | (N,T,D) | | 
| Kuramoto-Sivashinsky (D=128) | (N,T,D) | | 
| Kuramoto-Sivashinsky (D=256) | (N,T,D) | | 
| ERA5 | (T,C,H,W) |  | 

*NOTES: The five meteorological variables are in ERA5: 
* Geopotential 
* Temperature 
* Humidity 
* Wind speed (u-component)
* Wind speed (v-component)
