|   |URL|
|---------|---------|

| Kuramoto-Sivashinsky (D=128) | [Download](https://drive.google.com/file/d/1fAy2Vchje3AIcPWSUuER0_vLHRkTjpEv/view?usp=drive_link) |
| ERA5 | [Download](https://drive.google.com/file/d/1Rmj18sLiHk6OmOMOoHKHS6Gpi_ZRKhlY/view?usp=drive_link) |  

Please unzip each model’s compressed file into its corresponding working directory under the `training_scripts` folder. The notebooks will then correctly locate the file paths.
